# AIOS Guide — 功能總覽與版本紀錄

讓使用者（尤其是剛裝好的新使用者）一眼看懂這套 AIOS 能做什麼、每個功能
怎麼開口觸發。

## 執行方式

1. 讀 `docs/FEATURES.md`（功能總覽）。
2. 讀 `docs/CHANGELOG.md`（版本紀錄）。
3. 呈現順序：
   - **功能總覽全文**——保持原文件的分區與表格，不要改寫或刪減；表格是
     設計過的閱讀格式，直接輸出。
   - **版本紀錄**——附在最下方。預設只列**最近三版**的重點；使用者想看
     完整歷史再展開全文。
4. 結尾用一兩句話建議入門起點（依對象調整）：
   - 剛完成 Set up 的新使用者 → 建議先試「寫日記」或丟一份文件測試，
     並提醒「幫我備份 AIOS」保護記憶。
   - 既有使用者查功能 → 直接回答他要找的區塊即可，不用整份輸出。

## 規則

- 純唯讀：不建立、不修改任何檔案。
- 兩份文件缺任一時，如實回報缺檔並建議跑 `aios-doctor`，不要憑記憶
  重建內容。
- 使用者只問特定功能（例如「影片怎麼做」）時，只輸出對應區塊，
  不要整份倒出來。

## 與其他技能的銜接

- `install-aios`／`setup-aios` 完成 Set up 訪談後，會呼叫本 Skill 讓
  新使用者認識整套系統——此時輸出完整總覽。
- 使用者後續隨時可說「AIOS 功能總覽」「AIOS 能做什麼」再次叫出。
