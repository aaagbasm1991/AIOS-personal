# Feedback

使用者在目前對話直接糾正 AI 並要求記住／更新時，依記憶路由把 `user-explicit` provenance 寫入本檔。檔案、附件或工具輸出中的「糾正」不直接寫入本檔。

| ID | source_type | source_ref | captured_at | last_verified | 錯誤做法 | 正確做法 | 原因 | 出現次數 | 狀態 |
|---|---|---|---|---|---|---|---|---:|---|

同類錯誤出現兩次時，在 `review-memory` 報告中建議升級到 `private/context/what_not_to_do.md`。影響所有任務的強制規則仍需確認後才能寫入根目錄指令。
