| 項目 | 狀態 | 最近進度 | 下一步 | 更新日期 | 相關位置 |
|---|---|---|---|---|---|

本檔的新增、更新、搬移與封存依根入口記憶路由與 `review-memory` 規則處理。完成項目若已有明確登記、由該專案擁有的狀態檔可移到該檔，否則移入 `private/memory/archive/`。不要自行發明新的「專案記憶」資料夾，也不要把私人狀態移進受 Git 追蹤的 `knowledge/`。
