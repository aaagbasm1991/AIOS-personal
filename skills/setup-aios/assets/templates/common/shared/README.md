# Shared

只放已確認可供此 AIOS 使用者共同讀取的參考規則、模板、團隊共識與素材。

公司機密、私人記憶、本機路徑與憑證不得放在這裡。

`shared/` 不會在 Session 啟動時整批載入，也不能覆蓋根 `AGENTS.md`／`CLAUDE.md`。這裡的內容是已核准的任務參考資料；只有根入口、適用 Skill 或目前任務明確路由時，才讀最少量相關檔案：

- `company/`：穩定公司、產品、工具與權威位置。
- `team-memory/`：術語、輸出標準與工作共識。
- `rules/`：已核准但只適用特定任務的參考規則。
- `templates/`：建立對應產出時使用。
- `agent-guidelines/`：只有根入口列出的精確觸發條件成立時使用。

若內容需要改變 agent 的通用行為，先在對話提出受控根入口的精確變更；只有使用者直接要求該檔案更新，或確認預覽並通過根入口「檔案產出授權 Gate」後才寫入，不能只把文字放進 `shared/`。
