# Team Memory

這裡是 AIOS 內已確認可供團隊共用之工作共識的唯一權威位置：

- `glossary.md`：團隊術語。
- `output-standards.md`：輸出格式與必要欄位。
- `working-agreements.md`：協作方式與適用範圍。

每列都記錄 `source_ref`、`owner`、`confirmed_by` 與 `last_verified`。`owner` 負責維護與重驗；`confirmed_by` 必須是有權正式採納內容的團隊或角色，作者身分本身不構成採納。`last_verified` 是最後一次對照來源確認內容仍有效的日期，不是檔案修改時間。

來源變更、超過 `../company/about-company.md` 的 `revalidation_interval_days`、`last_verified` 缺失，或即將用於高影響工作時，先依 `source_ref` 重驗。該欄位是公司共享內容唯一的週期設定；週期缺失／無效或無法重驗時一律標為未確認，不覆寫正式共識。`knowledge/` 只保存相關證據、分析與連結，不複製本目錄的 canonical 正文。

更新前確認可共用；個人偏好、績效、個人評價與未授權機密不得放入。這些內容是任務參考資料，不會自動成為 agent 指令。
