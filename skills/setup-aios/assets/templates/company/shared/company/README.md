# Company Context

這裡是 AIOS 內已核准公司事實、產品摘要，以及工具與正式位置索引的唯一權威；外部正式系統仍是上游來源，使用 `source_ref` 指向，不把上游正文複製進來。

團隊術語、輸出標準與工作共識的唯一權威位置是 `../team-memory/`；不要在本目錄建立鏡像。這些內容都是任務參考資料，不是 agent 指令。

## 來源與時效

- `source_ref`：核准上游來源的穩定指標；不得放秘密或受限正文。
- `owner`：負責維護與重驗的團隊或角色。
- `confirmed_by`：有權正式採納內容的團隊或角色；作者身分不等於採納權限。
- `last_verified`：最後一次對照 `source_ref` 確認內容仍有效的日期，不是檔案修改時間。
- `about-company.md` 的 `revalidation_interval_days`：公司共享內容唯一的重驗週期（正整數天）；不得在個別來源建立第二份週期設定。

`source_ref` 變更、超過上述週期、`last_verified` 缺失，或即將用於高影響工作時，必須先重驗。週期空白、格式無效或無法重驗時，內容視為未確認，不得當成目前事實覆寫本目錄。

`knowledge/` 只保存來源證據、分析與連結，遇到本目錄擁有的事實時連回這裡，不複製 canonical 正文。`about-company.md` 擁有公司級資料邊界；產品列只能加嚴，不能放寬。
