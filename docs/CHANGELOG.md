# 版本紀錄（Changelog）

每一版寫的是「你多了什麼可以用」。安裝版本以 `.aios/version.md` 為準。

## [0.2.8] - 2026-08-01

- **全域整合補強**（修正實測回饋：裝完後技能只在 AIOS 資料夾內可用）：
  install-aios 現在會把「不整合＝其他資料夾用不到技能」的取捨講清楚並建議整合；
  sync-aios-global 補上逐一連結全域技能的具體步驟與數量驗證；
  aios-doctor 新增全域接入狀態檢查。已裝的人說「把 AIOS 同步到全域」即可補上。

## [0.2.7] - 2026-08-01

- **功能導覽（aios-guide）**：說「AIOS 能做什麼」隨時叫出功能總覽與版本紀錄；
  install-aios 完成 Set up 後自動向新使用者展示。
- 功能總覽全面表格化：記憶檔案結構、記憶操作與系統調整都改為表格呈現。

## [0.2.6] - 2026-08-01

- **每日反思日誌（journal）**：說「寫日記」就開始五題引導（事實→亮點→反思→改進→
  明日三件事），3 分鐘寫完存進記憶系統；明日待辦隔天自動出現在對話中。
- **完整備份（aios-backup）**：整套 AIOS 含 private/ 記憶與 AI 對話紀錄，
  備份到你自己的 GitHub 私有 repo；含新電腦還原流程。憑證永不進備份。

## [0.2.5] - 2026-08-01

- **AIOS 健檢（aios-doctor）**：一句話檢查雙入口規則有無漂移、技能三處是否一致、
  記憶結構是否完整，並引導驗證兩個工具是否真的載入了規則。只盤點不改檔。
- install-aios 安裝驗證加入 fresh-session 載入確認。

## [0.2.4] - 2026-08-01

- **理財功能自動選版**：用 Claude Code 自動載入官方最新版金融套件，用 Codex
  走內建版本——不用自己設定，兩邊功能相同、不重複觸發。

## [0.2.3] - 2026-08-01

- **投資理財 21 招**：DCF／LBO 估值、財報分析、同業比較、試算表稽核、
  投行級簡報 QC、晨會筆記……來自 Anthropic 官方金融套件（Apache-2.0），
  Claude Code 和 Codex 都能用。
- **3 個理財編排 Agent**：批次跑財報分析、產業研究打包、建模專員（Claude Code 專屬）。

## [0.2.2] - 2026-08-01

- **docs/ 文件區**：功能總覽（FEATURES.md）與本版本紀錄，首頁就能看懂這套在幹嘛。

## [0.2.1] - 2026-07-31

- **會議錄音 → 會議記錄**（meeting-notes-reference）：本機語音辨識
  （台灣國語＋中英夾雜特化）＋術語校正＋結構化整理，錄音不離開本機。
- **影片製作（HyperFrames，20 件）**：網址→宣傳片、文章→說明片、音樂→卡點片、
  影片上字幕、logo 動畫等，clone 完即可出片。
- **分鏡訪談（video-spec-builder）**：渲染前先以訪談方式把腳本整理成分鏡表。
- **社群圖卡（cards）**：筆記或網址輸出為可發佈的 IG／Threads 輪播 PNG。
- **烤問模式（grilling）**：動手前讓 AI 針對計畫漏洞逐一提問。
- **一句話裝機（install-aios）**：新電腦一句話安裝整套，完成後接續 Set up 訪談。

## [0.2.0] - 2026-07-31

- **初始發布**：雙工具入口（Claude Code＋Codex）、個人 Context 與長期記憶、
  Obsidian 相容知識庫、12 個基礎技能（文件處理、規劃、知識管理、去 AI 味潤稿）。
